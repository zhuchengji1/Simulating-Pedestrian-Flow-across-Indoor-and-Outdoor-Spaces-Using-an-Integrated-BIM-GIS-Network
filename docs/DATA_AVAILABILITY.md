# Data availability

Public synthetic code, anonymized Random passage-flow values, and published summary result tables are available from the GitHub repository: https://github.com/zhuchengji1/Simulating-Pedestrian-Flow-across-Indoor-and-Outdoor-Spaces-Using-an-Integrated-BIM-GIS-Network. Outdoor road and path data are available from OpenStreetMap. Point-of-interest data were obtained through the Amap API, subject to its access conditions. Population inputs for the simulations were estimated from annual admissions announcements and staff information publicly available on the Shenzhen University website. The BIM/IFC building models and the integrated pedestrian network derived from them cannot be made publicly available because they contain institutionally restricted building information. The public Random flow file contains only newly assigned sequence identifiers and flow values; it does not include network geometry or other restricted attributes. Passage-flow data for the Purposive and Simulated mechanisms are available from the corresponding author upon reasonable request.
