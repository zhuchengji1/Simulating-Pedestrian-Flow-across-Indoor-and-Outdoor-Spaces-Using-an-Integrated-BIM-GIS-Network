# Repository scope

This repository provides three public components:

1. A fully synthetic NetLogo example demonstrating passage-flow counting on a fictional 3 by 3 by 3 network.
2. An anonymized, non-spatial vector of Random segment passage-flow values.
3. Machine-readable versions of the summary tables reported in the manuscript.

The repository does not provide the empirical BIM/IFC models, the integrated pedestrian-network geometry, original segment identifiers, POI records, activity sequences, agent trajectories, spatially identifiable flow data, or a runnable copy of the full empirical NetLogo workflow.

The scripts in `code/01_network_construction/` document the network-preparation and stroke-merging procedures. Their source inputs are not included, so they are provided for methodological inspection and adaptation rather than direct execution.
