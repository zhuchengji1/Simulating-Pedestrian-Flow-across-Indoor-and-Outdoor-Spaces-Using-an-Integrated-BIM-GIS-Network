# Published table files

Each CSV in this directory reproduces the displayed values of the corresponding table in `Simcampus3D_V9.5.docx`.

- `Table_04_Pure_Power_Law_Fits_for_Network_Structural_Metrics.csv`: manuscript Table 4
- `Table_05_Passage_Flow_and_Network_Structure_Correlations.csv`: manuscript Table 5
- `Table_06_Passage_Flow_Concentration_by_Spatial_Subset_and_Analytical_Scale.csv`: manuscript Table 6
- `Table_07_Likelihood_Ratio_Comparison_of_Power_Law_and_Power_Law_with_Exponential_Cutoff.csv`: manuscript Table 7
- `Table_08_Power_Law_with_Exponential_Cutoff_Parameter_Estimates_and_Goodness_of_Fit.csv`: manuscript Table 8

The CSVs are summary outputs only. They do not contain coordinates, network identifiers, trajectories, raw structure metrics, or raw flow records.
